# Besterregen – Geometry Dash Listen

Statische Webseite für die Listen der Community.

## Dateien
- `index.html` – Startseite mit Listen
- `einreichen.html` – Seite zum Einreichen (Platzhalter)
- `data/listen.json` – alle Listen und Level (hier pflegen)
- `css/style.css`, `js/app.js` – Design und Logik

## Neue Liste anlegen
In `data/listen.json` einen neuen Eintrag unter `lists` ergänzen. Er erscheint automatisch als Tab.

## Hosting
Veröffentlichung über Cloudflare Pages: Repository verbinden, kein Build-Schritt nötig, Ausgabeordner ist der Hauptordner.
